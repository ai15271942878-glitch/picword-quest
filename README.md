# 🔍 PicWord Quest —— 看图寻词英语闯关

观察**真实摄影照片** → 写出与画面相关的英文单词 → 透明公式计分闯关 → 把生词连同图片收藏起来复习。

**🎮 在线试玩：<https://ai15271942878-glitch.github.io/picword-quest/>**（国内不翻墙可直接打开；手机、电脑都能玩）

## 快速开始

**方式一：双击** `启动游戏.bat`（首次会自动 `npm install`，然后自动打开浏览器）。

**方式二：命令行**

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173>。玩的时候保持命令行窗口开着（它同时提供大模型跨域代理）。

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发模式（含本地代理） |
| `npm run build` | 类型检查 + 生产构建到 `dist/` |
| `npm run preview` | 预览生产构建（同样含本地代理） |
| `npm test` | 运行 223 个单元测试 |

> 需要 Node.js 20+。

## 线上部署

`npm run build` 生成的 `dist/` 是纯静态网页，放到 Netlify / GitHub Pages 等静态托管即可，**AI 功能也能用**（四家大模型与图库均支持浏览器跨域，已实测）。步骤、平台国内可达性实测与注意事项见 **[部署指南.md](部署指南.md)**。

## 功能一览

- **21 个内置真实场景**（CC0 照片，离线可玩），每关 40~50 个分级词汇（核心 / 高阶 / 联想），随机抽取未玩过的关卡
- **离线判卷**：词形变化（复数、时态、比较级、英式拼写）+ 编辑距离拼写纠错（相邻字母换位也算 1 次），零延迟零费用
- **AI 判卷**：DeepSeek / 通义千问 / 智谱 / Gemini / 任意 OpenAI 兼容端点；AI 只判“拼写状态 + 关联度”，**总分由前端公式计算**
- **AI 搜图造关**：AI 构思场景 → 检索 Wikimedia / Openverse / Pexels / Unsplash 真实照片（不用 AI 绘图）→ 视觉模型看图校准词库
- **自建关卡**：上传 / 拖拽 / 粘贴自己的照片，AI 看图生成词库或手动编写
- **视觉生词本**：生词与图片绑定；遮英文 / 遮中文自测；Leitner 间隔复习
- **私人关卡库**：分类文件夹，AI / 自建关卡的图片与词库固化进 IndexedDB
- **存档**：一键导出 / 导入 `.json`（合并或覆盖）
- 其他：提示（中文 + 首字母）、计时、战绩统计、过关彩带、灯箱放大看图、美式发音

## 计分规则

- 关联度 ≥ 70% 的词才算达标：拼写正确计 1 个，轻微拼错计 0.5 个
- 未达及格数：`round(N_valid / N_pass × 60)`，绝不及格
- 达到及格数：`60 + min(30, 超额比例 × 30) + min(10, (平均关联度 − 70) / 25 × 10)`，封顶 100
